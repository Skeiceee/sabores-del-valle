# Frontend — Sabores del Valle

Aplicación Vue 3 + Vite + Tailwind CSS 4 con componentes Vuzeno.

```powershell
npm install
npm run dev
```

Abre <http://localhost:5173>. Las peticiones a `/api` se redirigen al backend FastAPI en
`http://localhost:8000` (ver `vite.config.ts`).

Instrucciones completas en el [README principal](../README.md).
